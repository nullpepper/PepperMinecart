# PepperMinecart 实机冒烟清单

MockBukkit 覆盖不到的行为（见 `verification-coverage-matrix.md` 末节），发布前在真实 Paper 服务器上逐项手测。
每项写明操作与预期；任何一项不符，记录现象与控制台日志。

## 0. 准备

- Paper 1.21.4（或生产所用版本），安装 PepperLib 与 `PepperMinecart-<版本>-all.jar`。
  - 注意：PepperLib 0.15.0 以上的前置插件以 Paper 26.x / Java 25 为目标；在 1.21.4 测试服上若它无法启用，
    PepperMinecart 也不会启用（`depend: [PepperLib]`），请先确认前置插件能正常加载。
- 一个 OP 账号 A（生存模式），最好再有一个账号 B（用于多人共享容器）。
- 测试前在 `0 0 0` 放一块石头：`/setblock 0 0 0 minecraft:stone`（用于第 3 节的检查）。
- 常用命令：
  - 生成普通矿车：`/summon minecart ~ ~ ~2`
  - 充能激活铁轨：`/setblock ~ ~ ~ minecraft:activator_rail[powered=true]`
  - 清理掉落物：`/kill @e[type=item,distance=..10]`
- 冷却与音效保持默认；需要改配置时改 `plugins/PepperMinecart/config.yml` 后执行 `/pm reload`。

## 2. 工作站（原版 MenuType 界面）

| # | 操作 | 预期 |
|---|---|---|
| 2.1 | 手持工作台，潜行右键空矿车 | 矿车显示工作台，手上少 1 个；播放木头放置音效 |
| 2.2 | 不潜行右键该矿车 | 打开原版合成界面，可正常合成 |
| 2.3 | 合成格里放材料后按 Esc | 材料回到背包（原版行为） |

| 2.6 | 附魔台矿车周围摆书架后打开 | 附魔等级按书架数量提升（原版按界面位置计算） |
| 2.7 | 潜行右键取下工作台 | 工作台回到背包，矿车恢复为空矿车，可以乘坐 |

## 3. 容器矿车（重点：(0,0,0) 不被改动）

| # | 操作 | 预期 |
|---|---|---|
| 3.1 | 木桶放上矿车，右键打开，放入物品，关闭 | 打开/关闭有木桶音效；界面标题为“木桶” |
| 3.2 | 检查 `0 0 0`：`/execute if block 0 0 0 minecraft:stone` | 仍是石头（旧实现会在这里放下一个木桶） |
| 3.3 | B 同时打开同一辆木桶矿车，A 放入物品 | B 的界面里实时出现同一物品 |
| 3.4 | 关服重启后再打开 | 内容仍在 |
| 3.5 | 潜行右键取下木桶，再把木桶放到地上打开 | 取下的木桶物品带着内容；放下后内容出现在方块里 |

| 3.7 | `container-pickup-policy: FORBIDDEN` 后潜行右键 | 提示“容器类方块取下已在配置中禁止”，木桶留在矿车上 |
| 3.8 | FORBIDDEN 下对潜影盒矿车潜行右键 | 正常取下，内容在潜影盒物品里 |
| 3.9 | 潜影盒矿车界面里尝试放入另一个潜影盒 | 放不进去（原版槽位规则） |
| 3.10 | 打开木桶矿车后走到 10 格外，回来再打开 | 界面已关闭；改动已保存 |

## 5. 铁砧
